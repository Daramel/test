#### 2.2.3 消费者配置

```java
@Component
@Slf4j
public class ReportGenerateConsumer {
    
    @Autowired
    private ReportGeneratorService reportGeneratorService;
    
    /**
     * 报告生成消息消费
     * 
     * 配置说明：
     * - prefetch: 每次拉取1条消息，防止内存溢出
     * - acknowledge-mode: MANUAL 手动确认，保证消息可靠性
     * - concurrency: 3-10 消费者数量，根据服务器配置调整
     */
    @RabbitListener(
        queues = "report.generate.queue",
        concurrency = "3-10",
        ackMode = "MANUAL"
    )
    public void handleGenerateMessage(
            ReportGenerateMessage message,
            Channel channel,
            @Header(AmqpHeaders.DELIVERY_TAG) long deliveryTag) {
        
        try {
            log.info("开始生成报告, reportId={}, enterpriseId={}", 
                     message.getReportId(), message.getEnterpriseId());
            
            // 调用报告生成服务
            reportGeneratorService.generateReport(message);
            
            // 手动确认消息
            channel.basicAck(deliveryTag, false);
            
            log.info("报告生成成功, reportId={}", message.getReportId());
            
        } catch (Exception e) {
            log.error("报告生成失败, reportId={}, error={}", 
                     message.getReportId(), e.getMessage(), e);
            
            // 根据重试次数决定是否重试
            if (message.getRetryCount() < 3) {
                // 重试：重新入队
                channel.basicNack(deliveryTag, false, true);
            } else {
                // 超过重试次数：拒绝消息，进入死信队列
                channel.basicNack(deliveryTag, false, false);
                
                // 更新报告状态为最终失败
                reportGeneratorService.markFailed(
                    message.getReportId(), 
                    "重试次数超限: " + e.getMessage()
                );
            }
        }
    }
}
```

### 2.3 数据采集流程

#### 2.3.1 数据采集编排器

```java
@Service
@Slf4j
public class DataCollectionOrchestrator {
    
    @Autowired
    private EnterpriseInfoClient enterpriseInfoClient;
    
    @Autowired
    private CreditScoreClient creditScoreClient;
    
    @Autowired
    private RiskDataClient riskDataClient;
    
    @Autowired
    private BlacklistClient blacklistClient;
    
    /**
     * 采集报告所需的所有数据
     * 
     * 使用 CompletableFuture 并行采集，加速处理
     */
    public ReportDataBundle collectData(Long enterpriseId, Integer reportType) {
        
        log.info("开始采集报告数据, enterpriseId={}, reportType={}", enterpriseId, reportType);
        
        // 1. 并行采集基础数据
        CompletableFuture<EnterpriseInfo> enterpriseFuture = 
            CompletableFuture.supplyAsync(() -> 
                enterpriseInfoClient.getInfo(enterpriseId)
            );
        
        CompletableFuture<CreditScore> scoreFuture = 
            CompletableFuture.supplyAsync(() -> 
                creditScoreClient.getLatestScore(enterpriseId)
            );
        
        CompletableFuture<List<RiskEvent>> riskFuture = 
            CompletableFuture.supplyAsync(() -> 
                riskDataClient.getRiskEvents(enterpriseId)
            );
        
        CompletableFuture<List<Shareholder>> shareholderFuture = 
            CompletableFuture.supplyAsync(() -> 
                enterpriseInfoClient.getShareholders(enterpriseId)
            );
        
        CompletableFuture<List<Executive>> executiveFuture = 
            CompletableFuture.supplyAsync(() -> 
                enterpriseInfoClient.getExecutives(enterpriseId)
            );
        
        CompletableFuture<List<ChangeRecord>> changeFuture = 
            CompletableFuture.supplyAsync(() -> 
                enterpriseInfoClient.getChangeRecords(enterpriseId)
            );
        
        // 2. 等待所有任务完成
        CompletableFuture.allOf(
            enterpriseFuture, scoreFuture, riskFuture, 
            shareholderFuture, executiveFuture, changeFuture
        ).join();
        
        // 3. 组装数据
        ReportDataBundle bundle = new ReportDataBundle();
        bundle.setEnterprise(enterpriseFuture.get());
        bundle.setCreditScore(scoreFuture.get());
        bundle.setRiskEvents(riskFuture.get());
        bundle.setShareholders(shareholderFuture.get());
        bundle.setExecutives(executiveFuture.get());
        bundle.setChangeRecords(changeFuture.get());
        
        // 4. 根据报告类型采集额外数据
        if (reportType >= 2) {
            // 标准版及以上：采集财务数据
            CompletableFuture<FinancialData> financeFuture = 
                CompletableFuture.supplyAsync(() -> 
                    enterpriseInfoClient.getFinancialData(enterpriseId)
                );
            bundle.setFinancialData(financeFuture.get());
        }
        
        if (reportType >= 3) {
            // 深度版：采集舆情数据
            CompletableFuture<List<Sentiment>> sentimentFuture = 
                CompletableFuture.supplyAsync(() -> 
                    riskDataClient.getSentiments(enterpriseId)
                );
            CompletableFuture<List<RelatedEnterprise>> relatedFuture = 
                CompletableFuture.supplyAsync(() -> 
                    enterpriseInfoClient.getRelatedEnterprises(enterpriseId)
                );
            bundle.setSentiments(sentimentFuture.get());
            bundle.setRelatedEnterprises(relatedFuture.get());
        }
        
        log.info("数据采集完成, enterpriseId={}, 数据项={}", 
                 enterpriseId, bundle.getDataCount());
        
        return bundle;
    }
}
```

### 3.1 技术选型对比

| 方案 | 模板技术 | PDF转换 | 优点 | 缺点 | 推荐度 |
|-----|---------|--------|------|------|-------|
| **方案一** | Thymeleaf | Flying Saucer | 模板易维护，CSS支持好 | 图片处理较弱 | ⭐⭐⭐⭐ |
| **方案二** | Freemarker | iText PDF | 功能强大，控制精确 | 模板语法复杂 | ⭐⭐⭐ |
| **方案三** | Vue SSR | Puppeteer | 前后端模板统一 | 资源消耗大，部署复杂 | ⭐⭐ |
| **方案四** | JSP | Apache PDFBox | 轻量级 | 功能有限 | ⭐⭐ |

**最终推荐：方案一（Thymeleaf + Flying Saucer）**

### 3.3 PDF生成实现

#### 3.3.1 PDF渲染服务

```java
@Service
@Slf4j
public class PdfRenderService {
    
    @Value("${report.template.path}")
    private String templatePath;
    
    @Value("${report.temp.path}")
    private String tempPath;
    
    @Autowired
    private TemplateEngine templateEngine;
    
    /**
     * HTML模板渲染
     * 
     * @param templateName 模板文件名（不含路径）
     * @param context 渲染上下文数据
     * @return 渲染后的HTML字符串
     */
    public String renderHtml(String templateName, Map<String, Object> context) {
        log.info("开始渲染HTML模板, template={}", templateName);
        
        Context thymeleafContext = new Context();
        thymeleafContext.setVariables(context);
        
        // 设置全局变量
        thymeleafContext.setVariable("renderTime", LocalDateTime.now());
        thymeleafContext.setVariable("pageNumber", 1);
        
        String html = templateEngine.process(templateName, thymeleafContext);
        
        log.info("HTML模板渲染完成, template={}, length={}", templateName, html.length());
        return html;
    }
    
    /**
     * HTML转PDF
     * 
     * @param html HTML内容
     * @param outputFile 输出文件路径
     * @param watermarkConfig 水印配置
     */
    public void convertHtmlToPdf(String html, File outputFile, 
                                  WatermarkConfig watermarkConfig) {
        log.info("开始转换PDF, htmlLength={}, output={}", html.length(), outputFile.getPath());
        
        try {
            // 1. 保存HTML临时文件
            File htmlFile = new File(tempPath, "temp_" + System.currentTimeMillis() + ".html");
            FileUtils.writeStringToFile(htmlFile, html, StandardCharsets.UTF_8);
            
            // 2. 配置Flying Saucer
            OutputStream os = new FileOutputStream(outputFile);
            ITextRenderer renderer = new ITextRenderer();
            
            // 设置资源路径（用于加载CSS、图片等）
```

```java
@Service
@Slf4j
public class WatermarkService {
    
    @Autowired
    private QrCodeUtil qrCodeUtil;
    
    /**
     * 添加水印到PDF
     */
    public void addWatermark(PdfWriter writer, WatermarkConfig config) {
        log.info("开始添加水印, config={}", config);
        
        PdfContentByte canvas = writer.getDirectContentUnder();
        
        // 添加文字水印
        if (config.isEnableTextWatermark()) {
            addTextWatermark(canvas, config);
        }
        
        // 添加图片水印
        if (config.isEnableImageWatermark()) {
            addImageWatermark(canvas, config);
        }
    }
    
    /**
     * 添加文字水印
     * 
     * 使用 PdfTemplate 创建可重复使用的水印图案
     */
    private void addTextWatermark(PdfContentByte canvas, WatermarkConfig config) {
        try {
            // 1. 创建水印图案
            float pageWidth = PageSize.A4.getWidth();
            float pageHeight = PageSize.A4.getHeight();
            
            // 2. 创建模板
            PdfTemplate template = canvas.createTemplate(pageWidth, pageHeight);
            
            // 3. 设置透明度和颜色
            template.setGState(new PdfGState() {{
                setFillOpacity(0.15f);  // 透明度15%
            }});
            
            // 4. 设置字体
            BaseFont bf = BaseFont.createFont(
                "C:\\Windows\\Fonts\\msyh.ttc,0",  // 微软雅黑
                BaseFont.IDENTITY_H,
                BaseFont.NOT_EMBEDDED
            );
            template.setFontAndSize(bf, config.getWatermarkFontSize());
            
            // 5. 计算水印重复次数
            int cols = (int) Math.ceil(pageWidth / config.getWatermarkSpacingX()) + 2;
            int rows = (int) Math.ceil(pageHeight / config.getWatermarkSpacingY()) + 2;
            
            // 6. 绘制水印文字
            template.beginText();
            template.setColorFill(new BaseColor(config.getWatermarkColor()));
            
            for (int row = -1; row < rows; row++) {
                for (int col = -1; col < cols; col++) {
                    float x = col * config.getWatermarkSpacingX() + (row % 2) * 75;
                    float y = row * config.getWatermarkSpacingY();
                    
                    // 旋转文字
                    template.showTextAligned(
                        Element.ALIGN_CENTER,
                        config.getWatermarkText(),
                        x, y,
                        config.getWatermarkRotation()
                    );
                }
            }
            
            template.endText();
            
            // 7. 将模板添加到每一页
            for (int i = 1; i <= writer.getCurrentPageNumber(); i++) {
                PdfContentByte cb = writer.getDirectContentUnder(i);
                cb.addTemplate(template, 0, 0);
            }
            
            log.info("文字水印添加完成");
            
        } catch (Exception e) {
            log.error("添加文字水印失败", e);
        }
    }
    
    /**
     * 添加图片水印（Logo）
     */
    private void addImageWatermark(PdfContentByte canvas, WatermarkConfig config) {
        try {
            // 加载Logo图片
            Image logo = Image.getInstance("classpath:static/logo.png");
            
            // 设置透明度
            logo.setGState(new PdfGState() {{
                setFillOpacity(0.3f);
            }});
            
            // 设置位置：页面底部居中
            logo.setAbsolutePosition(
                (PageSize.A4.getWidth() - logo.getWidth()) / 2,
                20
            );
            
            // 设置大小（宽度50mm，保持比例）
            logo.scaleAbsoluteWidth(50);
            logo.scaleAbsoluteHeight(logo.getHeight() * 50 / logo.getWidth());
            
            // 添加到模板
            PdfTemplate template = canvas.createTemplate(
                PageSize.A4.getWidth(), 
                PageSize.A4.getHeight()
            );
            template.addImage(logo);
            
            log.info("图片水印添加完成");
            
        } catch (Exception e) {
            log.error("添加图片水印失败", e);
        }
    }
    
    /**
     * 添加二维码水印
     */
    private void addQrCodeWatermark(PdfContentByte canvas, WatermarkConfig config) {
        try {
            if (config.getVerifyUrl() == null) {
                return;
            }
            
            // 生成二维码
            BufferedImage qrImage = qrCodeUtil.generate(
                config.getVerifyUrl(), 
                100, 100
            );
            
            // 转换为iText Image
            ByteArrayOutputStream baos = new ByteArrayOutputStream();
            ImageIO.write(qrImage, "PNG", baos);
            Image qr = Image.getInstance(baos.toByteArray());
            
            // 设置位置：页面右下角
            qr.setAbsolutePosition(
                PageSize.A4.getWidth() - 120,
                30
            );
            
            // 添加到当前页面
            canvas.addImage(qr);
            
        } catch (Exception e) {
            log.error("添加二维码水印失败", e);
        }
    }
}
```

```java
@Service
@Slf4j
public class AntiCounterfeitService {
    
    @Autowired
    private StringRedisTemplate redisTemplate;
    
    private static final String VERIFY_CODE_PREFIX = "report:verify:";
    private static final int VERIFY_CODE_EXPIRE_DAYS = 365;
    
    /**
     * 生成验证码和验证URL
     */
    public VerifyCodeResult generateVerifyCode(Long reportId) {
        // 1. 生成唯一验证码
        String rawCode = String.format("%d_%d_%s", 
            reportId, 
            System.currentTimeMillis(), 
            UUID.randomUUID().toString()
        );
        String verifyCode = DigestUtils.md5Hex(rawCode).substring(0, 8).toUpperCase();
        
        // 2. 存储到Redis
        String key = VERIFY_CODE_PREFIX + verifyCode;
        redisTemplate.opsForValue().set(key, String.valueOf(reportId), 
            VERIFY_CODE_EXPIRE_DAYS, TimeUnit.DAYS);
        
        // 3. 生成验证URL
        String verifyUrl = String.format(
            "https://credit.xxx.com/verify?code=%s", 
            verifyCode
        );
        
        log.info("生成验证码成功, reportId={}, verifyCode={}", reportId, verifyCode);
        
        return new VerifyCodeResult(verifyCode, verifyUrl);
    }
    
    /**
     * 验证验证码
     */
    public VerifyResult verifyCode(String verifyCode) {
        String key = VERIFY_CODE_PREFIX + verifyCode.toUpperCase();
        String reportIdStr = redisTemplate.opsForValue().get(key);
        
        if (reportIdStr == null) {
            log.warn("验证码无效, verifyCode={}", verifyCode);
            return VerifyResult.invalid("验证码无效或已过期");
        }
        
        Long reportId = Long.parseLong(reportIdStr);
        
        // 查询报告摘要信息
        CreditReport report = creditReportMapper.selectById(reportId);
        if (report == null) {
            return VerifyResult.invalid("报告不存在");
        }
        
        // 返回报告摘要（脱敏处理）
        VerifyResult result = new VerifyResult();
        result.setValid(true);
        result.setEnterpriseName(report.getEnterpriseName());
        result.setCreditRating(report.getCreditRating());
        result.setTotalScore(report.getTotalScore());
        result.setGenerateTime(report.getCreateTime());
        result.setReportNo(report.getReportNo());
        
        log.info("验证码验证成功, verifyCode={}, reportId={}", verifyCode, reportId);
        
        return result;
    }
}
```

#### 4.3.1 权限校验流程

```java
/**
 * 报告访问权限校验
 */
@Component
public class ReportAccessValidator {
    
    @Autowired
    private ReportGrantMapper reportGrantMapper;
    
    /**
     * 校验用户是否有权访问报告
     * 
     * 访问规则：
     * 1. 报告购买者本人可访问
     * 2. 被授权企业可访问（通过report_grant授权记录）
     * 3. 平台管理员可访问
     */
    public AccessResult validateAccess(Long userId, Long enterpriseId, Long reportId) {
        
        // 1. 查询报告信息
        CreditReport report = creditReportMapper.selectById(reportId);
        if (report == null) {
            return AccessResult.denied("报告不存在");
        }
        
        // 2. 校验报告是否已生成
        if (report.getGenerateStatus() != 3) { // 3=已完成
            return AccessResult.denied("报告尚未生成完成");
        }
        
        // 3. 校验报告是否过期
        if (report.getExpireTime() != null && 
            report.getExpireTime().isBefore(LocalDateTime.now())) {
            return AccessResult.denied("报告已过期");
        }
        
        // 4. 校验是否为报告归属企业
        if (report.getOwnerEnterpriseId().equals(enterpriseId)) {
            log.info("报告访问授权通过（归属企业）, userId={}, reportId={}", userId, reportId);
            return AccessResult.allowed();
        }
        
        // 5. 校验是否为被授权查看
        ReportGrant grant = reportGrantMapper.selectValidGrant(
            report.getEnterpriseId(),  // 报告所属企业
            enterpriseId               // 当前企业
        );
        
        if (grant != null) {
            // 校验授权范围
            if (grant.getGrantScope() == 1) {
                // 全部报告授权
                log.info("报告访问授权通过（被授权）, userId={}, reportId={}, grantId={}", 
                        userId, reportId, grant.getId());
                return AccessResult.allowed();
            } else {
                // 指定报告授权，校验是否在授权范围内
                if (isReportInGrantScope(grant, report)) {
                    log.info("报告访问授权通过（指定报告授权）, userId={}, reportId={}, grantId={}", 
                            userId, reportId, grant.getId());
                    return AccessResult.allowed();
                }
            }
        }
        
        // 6. 无访问权限
        log.warn("报告访问被拒绝, userId={}, enterpriseId={}, reportId={}", 
                 userId, enterpriseId, reportId);
        return AccessResult.denied("您没有权限查看此报告");
    }
    
    /**
     * 校验报告是否在授权范围内
     */
    private boolean isReportInGrantScope(ReportGrant grant, CreditReport report) {
        // 检查报告ID是否在授权报告ID列表中
        if (grant.getReportIds() != null) {
            List<Long> reportIds = JsonUtils.parseList(grant.getReportIds(), Long.class);
            if (reportIds.contains(report.getId())) {
                return true;
            }
        }
        
        // 检查报告类型是否在授权范围内
        if (grant.getReportTypes() != null) {
            String[] types = grant.getReportTypes().split(",");
            String reportType = String.valueOf(report.getReportType());
            for (String type : types) {
                if (type.trim().equals(reportType)) {
                    return true;
                }
            }
        }
        
        return false;
    }
}
```

```java
    int maxRetries() default 3;
    
    /**
     * 重试间隔（毫秒）
     */
    long retryInterval() default 5000;
    
    /**
     * 是否启用降级
     */
    boolean fallbackEnabled() default true;
    
    /**
     * 降级处理类
     */
    Class<? extends FallbackHandler> fallbackHandler() default DefaultFallbackHandler.class;
}

/**
 * 报告生成步骤执行器（带重试和降级）
 */
@Component
@Slf4j
public class ReportGenerateStepExecutor {
    
    @Autowired
    private RetryTemplate reportGenerateRetryTemplate;
    
    /**
     * 执行带重试的步骤
     */
    public <T> T execute(ReportGenerateStep step, Supplier<T> stepLogic) {
        String stepName = step.stepName();
        
        return reportGenerateRetryTemplate.execute(context -> {
            int attempt = context.getRetryCount() + 1;
            log.info("执行报告生成步骤, step={}, attempt={}", stepName, attempt);
            
            try {
                long startTime = System.currentTimeMillis();
                T result = stepLogic.get();
                long costTime = System.currentTimeMillis() - startTime;
                
                log.info("步骤执行成功, step={}, costTime={}ms", stepName, costTime);
                return result;
                
            } catch (Exception e) {
                log.error("步骤执行失败, step={}, attempt={}, error={}", 
                         stepName, attempt, e.getMessage());
                throw e;
            }
            
        }, context -> {
            // 重试失败后的回调
            log.warn("步骤重试失败, step={}, attempts={}", 
                    stepName, context.getRetryCount());
            
            // 执行降级处理
            if (step.fallbackEnabled()) {
                try {
                    return step.fallbackHandler()
                        .getDeclaredConstructor()
                        .newInstance()
                        .handle(stepName);
                } catch (Exception e) {
                    log.error("降级处理失败, step={}", stepName);
                }
            }
            
            return null;
        });
    }
}
```

```java
/**

public class DefaultFallbackHandler implements FallbackHandler {
    
    @Override
    public <T> T handle(String stepName) {
        switch (stepName) {
            case "数据采集":
                return (T) createEmptyDataBundle();
                
            case "评分计算":
                return (T) createDefaultScore();
                
            case "PDF生成":
                return (T) generateSimplePdf();
                
            case "文件上传":
                throw new ReportGenerateException("文件上传失败，降级处理无法继续");
                
            default:
                return null;
        }
    }
    
    private ReportDataBundle createEmptyDataBundle() {
        ReportDataBundle bundle = new ReportDataBundle();
        bundle.setEmpty(true);
        return bundle;
    }
    
    private CreditScore createDefaultScore() {
        CreditScore score = new CreditScore();
        score.setTotalScore(500);              // 默认中等评分
        score.setCreditRating("BBB");          // 默认BBB等级
        score.setIsDefault(true);               // 标记为默认评分
        return score;
    }
    
    private File generateSimplePdf() {
        // 生成仅包含基本信息的简化PDF
        // 可以在此处调用专门的简化模板
        return pdfRenderService.generateSimplePdf();
    }

@Component
public class DataCollectionFallbackHandler implements FallbackHandler {
    
    @Autowired
    private RedisTemplate<String, Object> redisTemplate;
    
    @Override
    public <T> T handle(String stepName) {
        // 尝试从缓存获取历史数据
        Long enterpriseId = getCurrentEnterpriseId();
        String cacheKey = "report:data:backup:" + enterpriseId;
        
        @SuppressWarnings("unchecked")
        ReportDataBundle cachedData = (ReportDataBundle) redisTemplate.opsForValue().get(cacheKey);
        
        if (cachedData != null) {

            return (T) cachedData;
        }
        
        // 无缓存，返回空数据结构
        log.warn("数据采集降级，返回空数据, enterpriseId={}", enterpriseId);
        return (T) new ReportDataBundle();
    }
```

#### 6.1.2 进度更新服务

```java
@Service
@Slf4j
public class GenerateProgressService {
    
    @Autowired
    private StringRedisTemplate redisTemplate;
    
    private static final String PROGRESS_KEY_PREFIX = "report:progress:";
    private static final int PROGRESS_EXPIRE_HOURS = 24;
    
    /**
     * 更新生成进度
     */
    public void updateProgress(Long reportId, GenerateProgress progress) {
        String key = PROGRESS_KEY_PREFIX + reportId;
        
        Map<String, Object> progressData = new HashMap<>();
        progressData.put("percent", progress.getPercent());
        progressData.put("message", progress.getMessage());
        progressData.put("step", progress.name());
        progressData.put("updateTime", System.currentTimeMillis());
        
        redisTemplate.opsForHash().putAll(key, progressData);
        redisTemplate.expire(key, PROGRESS_EXPIRE_HOURS, TimeUnit.HOURS);
        
        log.debug("更新生成进度, reportId={}, progress={}", reportId, progress);
        
        // 可选：发送WebSocket通知前端
        sendProgressNotification(reportId, progress);
    }
    
    /**
     * 获取生成进度
     */
    public GenerateProgressVO getProgress(Long reportId) {
        String key = PROGRESS_KEY_PREFIX + reportId;
        
        Map<Object, Object> data = redisTemplate.opsForHash().entries(key);
        
        if (data.isEmpty()) {
            return null;
        }
        
        GenerateProgressVO vo = new GenerateProgressVO();
        vo.setPercent((Integer) data.get("percent"));
        vo.setMessage((String) data.get("message"));
        vo.setStep((String) data.get("step"));
        vo.setUpdateTime((Long) data.get("updateTime"));
        
        return vo;
    }
    
    /**
     * 获取预估剩余时间（基于历史数据统计）
     */
    public Long estimateRemainingTime(Integer currentPercent) {
        // 基于历史生成时间统计
        // 例如：已完成30%，预计还需2分钟
        // 可以通过查询历史平均生成时间计算
        if (currentPercent < 30) {
            return 180L;  // 3分钟
        } else if (currentPercent < 60) {
            return 120L;  // 2分钟
        } else if (currentPercent < 85) {
            return 60L;   // 1分钟
        } else {
            return 30L;   // 30秒
        }
    }
}
```

```java
        return Result.success(progress);
    }
```

```java
@Service
@Slf4j
public class OssStorageService {
    
    @Value("${aliyun.oss.bucket-name}")
    private String bucketName;
    
    @Value("${aliyun.oss.endpoint}")
    private String endpoint;
    
    @Autowired
    private OSS ossClient;
    
    /**
     * 上传报告PDF文件
     */
    public String uploadReportPdf(File pdfFile, Long reportId, String reportNo) {
        // 1. 生成存储路径
        LocalDate now = LocalDate.now();
        String objectName = String.format(
            "reports/%d/%02d/%d/v1.pdf",
            now.getYear(), now.getMonthValue(), reportId
        );
        
        // 2. 上传到OSS
        try (FileInputStream fis = new FileInputStream(pdfFile)) {
            ossClient.putObject(bucketName, objectName, fis);
            
            // 3. 生成访问URL（签名URL，1小时有效期）
            Date expireTime = new Date(System.currentTimeMillis() + 3600000);
            URL url = ossClient.generatePresignedUrl(bucketName, objectName, expireTime);
            
            log.info("报告上传成功, reportId={}, objectName={}", reportId, objectName);
            
            return url.toString();
            
        } catch (Exception e) {
            log.error("报告上传失败, reportId={}", reportId, e);
            throw new ReportGenerateException("报告上传失败: " + e.getMessage(), e);
        }
    }
    
    /**
     * 生成永久访问URL（需配置bucket为公共读）
     */
    public String getPublicUrl(String objectName) {
        return String.format("https://%s.%s/%s", bucketName, endpoint, objectName);
    }
    
    /**
     * 生成带签名的临时访问URL
     */
    public String getSignedUrl(String objectName, long expireSeconds) {
        Date expireTime = new Date(System.currentTimeMillis() + expireSeconds * 1000);
        URL url = ossClient.generatePresignedUrl(bucketName, objectName, expireTime);
        return url.toString();
    }
```

## 九、总结

### 9.1 关键技术点

| 技术点 | 实现方案 |
|-------|---------|
| **异步生成** | RabbitMQ消息队列，支付成功 → 消息入队 → 异步消费 |
| **并行采集** | CompletableFuture，并行采集多源数据，缩短总耗时 |
| **模板渲染** | Thymeleaf模板引擎，HTML模板 + 数据 → 渲染HTML |
| **PDF转换** | Flying Saucer + iText，HTML → PDF，支持中文 |
| **动态水印** | PdfTemplate + PdfContentByte，页级水印覆盖 |
| **防伪验证** | MD5验证码 + Redis存储 + 扫码验证 |
| **权限校验** | 三级校验：归属企业、被授权查看、管理员 |
| **错误重试** | Spring Retry + 指数退避 + 降级处理 |
| **进度追踪** | Redis Hash存储 + WebSocket推送 |
